## Learnings

- [Review technique — gate scoping] A fail-closed gate built from `find <fixed-dir>` / `grep -r <fixed-dirs>` enforces a repo-wide claim only where it looks; test gates on the **location** axis (plant a violating artifact outside the scan roots), not only the **content** axis (byte mutation). Demonstrate empirically and revert with a proven-identical `git status` — reading the source alone invites "but another gate covers it". → `skills-pending/fail-closed-gate-scope-probe`
- [Review technique — reproduction claims] "Reproduced" verified by re-running the project's own test proves only self-consistency; the test's literal and the authority's constant are two copies that can diverge. Recompute with an implementation the project does not own, self-validated against published vectors first, and compare against the **authority's** value. Read build semantics off the artifact metadata, not the config. → `skills-pending/independent-constant-reproduction`
