# VUX

VUX is a fair-mined protocol with a WETH Hard Reserve, distributed entirely
through permissionless mining.

**Fair · Simple · Elegant · Secure**

## Status

Pre-implementation. Entering Loa planning.

No contracts have been written. No production deployment is authorized from
this repository yet.
