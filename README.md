# VUX

VUX is a fair-mined KOTH protocol combining an ownerless WETH Hard Reserve,
a productive Strategic Treasury, protocol-owned market infrastructure, and
bounded holder-directed Strategic allocation.

**Fair · Simple · Elegant · Secure**

## Status

Pre-implementation. The Strategic-Treasury superseding authority set was
accepted by the operator on 2026-08-09 and is current.

No contracts have been written. No production deployment is authorized from
this repository yet.

`SUPERSEDED_BEFORE_OPERATOR_ACCEPTANCE` historical generation evidence. It is
not current authority and must not be patched. The authorized next lifecycle
node is a fresh `/plan-and-analyze` cycle against the accepted authority.
